# Image drop-in guide — every blog post

Every post's front matter now points at a featured image in `src/assets/img/blog/`.
Save each generated image as **WebP**, name it **exactly** as listed, and drop it in
that folder. The card fills in automatically on the next build — nothing else to wire.

> **Why your cards are blank right now:** the front matter is correct, but the actual
> `.webp` files aren't in the repo yet (they're on your machine). The card shows an
> empty box until the matching file lands in `src/assets/img/blog/`. Commit the files
> there and they appear.

House style for every prompt: **subject/topic + psychedelic gothic drip cartoon.**
